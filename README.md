# Loan Investment & IRR Analysis Model

## Overview
This project is a financial modelling dashboard built in Google Sheets.

The model combines:
- Loan amortization analysis
- Discounted cash flow (DCF)
- Present Value (PV)
- Net Present Value (NPV)
- Internal Rate of Return (IRR)
- Investment payback analysis

---

## Features
- Dynamic loan assumptions
- Loan amortization table
- IRR & NPV calculations
- Discounted cash flow analysis
- Executive finance dashboard
- Investment payback visualisation

---

## Financial Metrics
- IRR
- NPV
- Payback Period
- Total Interest Earned
- Discount Rate
- Loan Amount

---

## Tools Used
- Google Sheets
- Financial Modelling
- DCF Analysis
- Investment Analysis
